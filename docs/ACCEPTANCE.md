# 受入試験・証拠の要件

本表は生成するサービスに適用する試験仕様であり、試験結果ではない。期待値だけ書いたモック出力を実行証拠としない。

| ID | 試験 | 合格条件 |
|---|---|---|
| NET-01 | 別ネットワークから実URLに接続 | 私設経路外は到達不可。試せなければ未確認 |
| NET-02 | 未承認の私設ネットワーク端末 | ACL等で拒否。許可端末でもアプリ未認証はAPI/WS/media拒否 |
| AUTH-01 | 接続コードの期限/再利用/並行消費/総当たり | 期限切れ拒否、単回消費、試行制限が働く |
| AUTH-02 | 認証済み端末を個別失効 | HTTP拒否、既存WS閉鎖、他端末は維持 |
| AUTH-03 | 中継再起動 | 端末認証の維持が仕様通り。私有状態を公開しない |
| WEB-01 | 異なる/欠落Origin、不正Host、偽Forwarded、CSRF | 許可されない接続/変更を拒否 |
| WEB-02 | HTML/script属性/悪意Markdown/外部画像 | コード実行・自動追跡通信がない |
| WEB-03 | ネットワークログと例外ログ | token/code/Cookie/鍵/実パス/会話本文なし |
| FILE-01 | 絶対パス、traverse、エンコード/二重エンコード、リンク/ジャンクション | 許可領域外を読まない。入力正規化だけで合格にしない |
| FILE-02 | メディアID盗用、別会話、秘密ファイル、拡張子偽装 | 認可/型検査で拒否。ID自体を認証にしない |
| FILE-03 | 大容量/大量添付、Range、不正filename | サイズ/個数/転送制限、ファイル名の安全化、既存ファイル非上書き |
| AGENT-01 | agentへ境界外ファイルの取得を指示 | 境界を主張するならツール/OSでも拒否。拒否できなければ権限が広いと明記 |
| RPC-01 | 未許可method/余計なfield/別profile/任意URL | バックエンドへ転送前に拒否 |
| CHAT-01 | 同じlive会話へ閲覧/接続/切断 | 保存IDとownerが不変、別agentなし。送信試験とは区別 |
| CHAT-02 | 試験会話で送信/応答/停止/承認 | 各対象IDが一致し実結果を読み戻せる。料金試験は承認済み |
| CHAT-03 | timeout/復帰/二重タップ | 不確定promptを自動再送せず入力と添付を保持 |
| CHAT-04 | 会話切替中に旧応答/旧承認を返す | 対象世代が異なる結果は破棄 |
| OWN-01 | 使用中会話を明示引き継ぎ | 本人の二段目確認、正規終了→解放→同保存ID再開。無承認停止なし |
| OWN-02 | owner差替え/失効/解放遅延/制御口なし | 競合再開・kill・lease編集をせず中断 |
| MODEL-01 | 下書き/会話だけのモデル選択 | readbackで対象だけ変化、既定/他会話は不変。実推論確認は別 |
| GPU-01 | 複数GPU/0/N/A/失敗/遅延 | GPU別、nullと0を区別、時刻と失敗/古い値を表示 |
| GPU-02 | 任意command/host/転送/鍵差替え | 監視権限では実行不可。host key不一致を拒否 |
| GPU-03 | 高使用率でも待ちAPIなし | 推論待ちや残り時間を推測しない |
| UI-01 | iPhone入力/回転/画面復帰/全画面動画 | 実機で確認。合成viewportを実機と称さない |
| OPS-01 | 候補更新/rollback/ログイン自動起動 | 配信hashとownerを読戻し、共有サービス不変。ログイン跨ぎは実試験 |
| PUB-01 | 公開候補の内容/名前/リンク/全Git履歴 | 不要な情報なし。全履歴未検査なら公開不可 |

## 証拠の分離

- 合成テスト：状態遷移や想定エラーの検査。実サーバーが安全という証拠ではない。
- 隔離HTTP/WS：認証・ルーティングの検査。本番ネットワークの到達制限とは別。
- 正規API：会話同一性や結果の検査。ブラウザ描画・実機の証拠とは別。
- ブラウザ：独立Context・専用試験端末。本人のCookieや全ブラウザ状態を消さない。
- 実機：端末名は匿名化し、本人が確認した項目だけ合格。

報告に残すのはテストID、対象候補版、成功/失敗/未確認、実行相関ID、秘密を除いた結果。試験fixtureが空でも本物のログを公開リポジトリへ入れない。内部証拠は非公開、公開側は検証範囲と限界だけをまとめる。
